# Eldoria Chronicles

A text-based fantasy RPG built in Python with a deep branching story, turn-based combat, exploration, crafting, companions, achievements, and multiple endings.

## Story

One hundred years ago, the sorcerer Malachar shattered the five Crystal Shards that kept Eldoria alive. A prophecy survives: *'One soul from the dust shall rise — and either save the world, or become its end.'* That soul is you.

## Features

- **5-act main story** with branching dialogue and meaningful choices
- **8 character classes** in the expanded edition
- **Turn-based combat** with skills, items, weather effects, companions, and enemy abilities
- **Levelling system** with XP and stat growth
- **Inventory and crafting** with multiple recipes
- **Random travel encounters** and exploration events
- **Companions** who can fight and support you
- **Bestiary and achievements**
- **Reputation and titles** that react to your choices
- **5 endings**, including secret and dark outcomes
- **Save/load system** with checkpoints

## Deluxe Long-Road Campaign

The repository now also includes `eldoria_chronicles_deluxe.py`.

The Deluxe Campaign keeps the original game intact and wraps a much longer optional story around it. After each main act, you can play **three additional story chapters**, for **15 extra chapters total** across Greenhollow, Ironpeak, Arcane Spire, Duskmar, and the Void Frontier.

These chapters add new mysteries, dialogue choices, exploration decisions, extra encounters, reputation changes, XP, stat rewards, item rewards, and additional save checkpoints. A complete playthrough is therefore substantially longer than the original five-act route.

### Expanded shop

The Deluxe Campaign replaces the basic travelling merchant with a much more detailed caravan shop. Every item now has a proper description and the merchant can explain categories of supplies before you buy.

The expanded caravan includes healing supplies, permanent character upgrades, exploration maps, magical curios, lore books, a mystery box, and other useful travel items. You can also sell selected supplies and browse the merchant's advice.

## How to Play

Original campaign:

```bash
python3 eldoria_chronicles.py
```

Longer Deluxe campaign:

```bash
python3 eldoria_chronicles_deluxe.py
```

No third-party dependencies are required; both versions use the Python standard library and the original game file.
